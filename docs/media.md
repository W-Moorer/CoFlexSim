# 动画与场量

三例各 3 段 MP4，共 9 段：1280×720、60 fps、600 帧、10 s、H.264/yuv420p、faststart。齿轮物理时长 0.5 s，慢放 20 倍；凸轮物理时长 10 s。

场量由同一 FE 母模型在后处理恢复：`u = Φq + K⁻¹Sᵀf − ΦKr⁻¹Φsᵀf`，并与接触表面解核对。体参考系的小应变来自线性四面体位移梯度，应力使用原材料参数。应力显示 von Mises，等效偏应变为 `sqrt(2/3 ε_dev : ε_dev)`。表面场值来自相邻四面体，不做跨齿视觉平滑。

应力和应变采用固定接触区特写，左下角保留整体位置小图。视窗根据整段轨迹承力节点的位置确定，不逐帧追踪应力峰值。模型视频显示完整机构和接触视窗轮廓。

每例每场使用全段固定色标，变形比例为 1。短色条采用明确标注的平方根颜色映射 `color = cmap(sqrt(value / limit))`，使中低值区域更易辨认；色条端点仍是实际物理量。若接触区最大值超过其正值 P99.5 的四倍，则固定采用 P99.5 作为显示上限，并以 `≥` 标明饱和；完整表面峰值在每帧单独显示，饱和比例记录在 `provenance/media_v2/`。没有对计算场量作平滑或幅值放大。

线性四面体内应变为常量，因此云图保留单元分片。60 fps 是播放帧率，视频帧选取最近的已接受采样状态，不代表积分步长或新增计算状态。齿轮场量每 8 步采样一次，凸轮每 32 步采样一次；完整响应 CSV 保留每个时间步。

场恢复、轨迹采样和绘图不计入干净在线性能。九个独立 MP4 位于 v0.2.0 Release，同时作为 GitHub 原生视频附在 README；文件校验见 `provenance/release_assets.json`。
