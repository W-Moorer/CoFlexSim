# 算例与复现

`case.json` 指定网格哈希、步长、模态、缓存预算和容差。更换网格、材料、约束或模态后必须重新准备算子。

`fetch-data` 下载三个场景及细网格直齿轮表面模态／惯性算子和 200 ms 初态，SHA-256 见 `data_manifest.json`。数组为不启用 pickle 的 NPZ。细网格 445 + 900 参考模态在线收缩到 112 + 225，其余由残余柔度恢复；发布预计算数据用于复用相同空间。完整 FE 材料、网格和约束仍在 `scene.json`。

`prepare` 构建刚度和残余库、核查抽样列并生成保守边界。库按对称分块存为 `.f64`，封存状态与模型身份另存。已有算子和完成的库分段可复用。直齿轮建议至少预留 12 GiB 数据空间及额外构建、下载和 OS 余量。

1. 构建并运行 `check`，下载数据。
2. 先 `prepare cam`，再分别运行三个后端。
3. 正式重复使用新进程与不同输出名；计时和 `--memory` 分开。
4. `--full` 推进齿轮 0.5 s／凸轮 10 s。
5. 直齿轮短窗使用 `--restart gpu-contact/data/spur/short_window_state.npz --steps 96`；不传则从原始初态运行。

不要按短段时间比例外推完整轨迹。输出分别记录加载、初始化、在线与离线信息。发布入口使用可恢复文件库；历史斜齿轮／凸轮测量使用主机 RAM 库，本机复现需记录页缓存状态。当前 CPU 实现不等于商业 FEM 或最优 CPU 求解器。
